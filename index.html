Key words to know

Event

One or more outcomes.

Sample space

All possible outcomes. Each one is a sample point.

n factorial (n!)

Product of all integers from n down to 1.

Linear permutation

Objects arranged in a row.

Distinguishable

Some objects are alike, so some arrangements look the same.

Say it: Permutation = an arrangement where order matters. ABC and CBA are different.

Fundamental Counting Principle

If one event can happen in m ways and another in n ways, both can happen in

m × n ways

School lunch: 2 main dishes × 2 side dishes × 2 drinks × 3 desserts

2×2×2×3=24

Say it: Each choice multiplies the options. 24 different lunches are possible.

Factorial notation

n! means multiply a descending series of natural numbers.

3! = 3 × 2 × 1 = 6

4! = 4 × 3 × 2 × 1 = 24

5! = 5 × 4 × 3 × 2 × 1 = 120

6! = 720   7! = 5,040   8! = 40,320

Say it: "5!" is read "five factorial." It grows very fast!

Working with factorials

Multiply

5!2! = 120 × 2 = 240

6!3! = 720 × 6 = 4,320

Divide: cancel!

10!/5! = 10·9·8·7·6·5!/5! = 30,240

8!/(3!2!) = 6,720/2 = 3,360

Add / subtract

6! − 4! = 720 − 24 = 696

7! + 2! = 5,040 + 2 = 5,042

Say it: When dividing, write out the bigger factorial until it matches the smaller one, then cancel. For + and −, compute each factorial first.

Permutation of n objects, all at once

ₙPₙ = n!

5 cars finish a race, no ties.

₅P₅ = 5! = 120 ways

10 books on a shelf.

₁₀P₁₀ = 10! = 3,628,800

6 numbers in a lottery code.

₆P₆ = 6! = 720

Say it: First place has n choices, next n−1, next n−2 … down to 1.

Taking r at a time

ₙPᵣ = n! ÷ (n − r)!  where r < n

5 cars, first 2 places:

₅P₂ = 5!/3! = 5·4 = 20

7 chairs, 3 people:

₇P₃ = 7·6·5 = 210

President, Secretary, Treasurer from 12:

₁₂P₃ = 12·11·10 = 1,320

Say it: Only multiply the first r numbers of the factorial. The rest cancels.

Permutations without repetition

How many 4-digit numbers from 1, 3, 4, 6, 8, 9 if no digit repeats?

6×5×4×3=360

thousands · hundreds · tens · ones

3-letter words from D, A, P (no repeat): 3 × 2 × 1 = 6 (DAP, DPA, ADP, APD, PDA, PAD)

Say it: Each place has one fewer choice, because one item is already used.

Permutations with repetition

P = nʳ

n = things to choose from, r = how many we choose. Repeats allowed, order matters.

5-item true/false exam

2⁵ = 32

3-letter words from DAP, repeats OK

3³ = 27

5-digit security code (0–9)

10⁵ = 100,000

Jane's password: 3 letters (21 choices) then 2 digits (1–9): 21³ × 9 × 9 = 750,141

Say it: Same number of choices every time, so just multiply n by itself r times.

Permutations with some alike

P = n! ÷ (p! q! r! …)

BEER (two E's)

4!/2! = 12

BANANA (A×3, N×2)

6!/(3!·2!) = 60

RESPECT (two E's)

7!/2! = 2,520

Say it: Swapping two identical letters changes nothing, so divide out those duplicate arrangements.

Which formula do I use?

All items, no repeat

n!

r of n, no repeat

n!/(n−r)!

Repeats allowed

nʳ

Some items alike

n!/(p!q!…)

Ask yourself: Does order matter? Can items repeat? Are some items identical?
